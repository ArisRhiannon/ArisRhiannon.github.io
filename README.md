# Aris Rhiannon

Sitio personal y archivo de proyectos publicado en
[arisrhiannon.github.io](https://arisrhiannon.github.io/).

## Desarrollo local

```sh
npm install
npm run dev
```

El servidor abre por defecto en `http://localhost:4321`.

## Comprobación

```sh
npm run build
npm run preview
```

## Estructura

- `src/layouts/SiteLayout.astro`: navegación, pie y sistema visual compartido.
- `src/pages/`: páginas y rutas del sitio.
- `public/`: imágenes, descargas y archivos estáticos.

La rama `main` se publica automáticamente mediante GitHub Pages.
